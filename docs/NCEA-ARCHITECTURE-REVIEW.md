# Сравнение архитектур NCEA и ARGENTI

Источник: структура проекта Supabase `bualqaeinwifoopzflbt` в организации NCEA, изученная только запросами к системному каталогу и списком таблиц 12 ноября 2026 года. Содержимое пользовательских записей не читалось, проект не изменялся.

| Область | NCEA | ARGENTI и решение |
| --- | --- | --- |
| Профиль | `profiles.id` ссылается на `auth.users.id`; временные метки `timestamptz` | Сохранена связь с Auth, `created_at` и `updated_at` |
| Роли | Отдельная `user_roles`, enum `app_role`, уникальная роль на пользователя | В ARGENTI одна роль в `profiles.role`: проще для четырёх фиксированных полномочий; отдельный справочник `senate_roles` описывает роли |
| Проверка ролей | `private.has_role` — `SECURITY DEFINER` с фиксированным `search_path` | Аналогичная проверка в неэкспонируемой `private.has_any_role`; клиентская роль не считается защитой |
| Назначение ролей | `public.set_user_role` — привилегированная функция с проверкой администратора | Не переносим в публичную схему. Первый председатель назначается доверенным администратором по подтверждённому UUID |
| Публичность профилей | Политика NCEA разрешает читать все профили | В ARGENTI профиль виден владельцу и редакторам; персональные данные не публикуются автоматически |
| RLS | Включён на всех 18 таблицах `public`, отдельные политики для чтения и записи | Включён на всех 12 таблицах ARGENTI; публичные запросы ограничены опубликованными материалами |
| Аудит | Триггеры административного журнала для ролей и настроек; индекс по времени | Транзакционные триггеры для заседаний и решений, отдельная история статусов; индексы по сущности и времени |
| Время и связи | `timestamptz`, внешние ключи на Auth и профили, индексы по связям | Использованы те же принципы; время заседания отображается по `Europe/Moscow` |

NCEA служит только архитектурным образцом. Его таблицы, пользователи, настройки и данные не копируются в ARGENTI. Выявленные особенности публичного чтения профилей и привилегированной функции в `public` сознательно не повторены.

Создание отдельного `ARGENTI-Senate` сначала в NCEA, затем по уточнению пользователя в `nelli-english` отклонено Supabase. В обоих случаях оценка нового проекта составляла $0/месяц, но владелец достиг лимита двух активных бесплатных проектов суммарно по организациям. Существующие проекты не менялись. Для нового проекта требуется освободить бесплатный слот без удаления данных либо отдельно согласовать платный тариф после получения его стоимости.
